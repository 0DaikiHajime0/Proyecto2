Spotify Artist Streaming Analytics 2015–2025
📊 About This Dataset
This dataset is designed for exploring Spotify artist performance, streaming trends, popularity, and music characteristics from 2015 to 2025.

It is derived from the Spotify Music Analytics Dataset (2015–2025), which contains 85,000 synthetic tracks with metadata, audio features, popularity scores, streaming counts, countries, genres, and label information.

The original dataset is fully synthetic and was created to represent realistic patterns in modern music streaming behavior. Therefore, the data should be used for educational, analytical, visualization, and machine learning purposes, rather than as official Spotify streaming statistics.

🎯 Purpose
The dataset can be used to investigate questions such as:

Which artists have the highest streaming performance?
How does artist popularity relate to streams?
Which genres generate the most streams?
How has music streaming changed from 2015 to 2025?
What audio characteristics are associated with popular music?
Which artists have the strongest performance relative to their number of tracks?
How do streaming patterns vary across countries?
